# Agent Execution Harness v0.10.0

Dependency-aware execution for multi-step plans.

Added:

- Optional task `depends_on` in `agent_harness_plan_v1`.
- Graph validation for missing dependencies, self-dependencies and cycles.
- `agent-harness plan waves --plan <plan.json>` to preview safe execution waves.
- Dependency-aware `next --exact`, so weak agents only receive unblocked tasks.
- Compact dependency context in `handoff` packets.

No automatic multi-agent spawning was added. The harness stays deterministic and token-light.
