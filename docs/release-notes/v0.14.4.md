# Agent Execution Harness v0.14.4

Patch release focused on reusing user-approved plans from files and chat output.

What changed:

- Added `agent-harness plan import --from -` for approved plans pasted or piped from Codex, OpenCode or another chat agent.
- Kept file import with `agent-harness plan import --from backlog.md`.
- Refused to overwrite an existing `--out` plan unless `--overwrite` is explicit.
- Updated missing-plan guidance to tell agents how to turn approved chat plans into `plan.json`.

Compatibility:

- Existing `--plan plan.json` flows keep working.
- Existing file-based `plan import --from backlog.md` flows keep working.
- The importer still accepts only the atomic checklist backlog format; it does not infer plans from unstructured conversation.
