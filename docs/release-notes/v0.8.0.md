# Agent Execution Harness v0.8.0

Token-light handoff release for strong-planner / weak-executor workflows.

Added:

- `agent-harness handoff` generates a compact JSON-only task capsule for weak workers.
- `agent-harness handoff validate` checks returned worker JSON before the main agent trusts it.
- Validation rejects out-of-plan files, out-of-plan commands, placeholders and `done` without evidence.

No new runtime dependency.
