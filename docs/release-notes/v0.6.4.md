# Agent Execution Harness v0.6.4

Patch release for scope-safe weak-agent execution.

## Added

- Scope guard checks git diff before `finish`.
- Runs record touched files and unexpected files in artifacts.
- `unexpected_file_changed` repair hints tell agents to revert or explicitly add out-of-plan files.
- Weak-agent simulation proves completion is blocked when the agent changes files outside the plan.

## Validation

- Unit scope guard tests.
- CLI integration test for finish blocking.
- Public readiness weak-agent simulation.
