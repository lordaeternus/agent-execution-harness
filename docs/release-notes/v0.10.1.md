# Agent Execution Harness v0.10.1

Patch release for token-efficient executor output.

Add:

- `next --exact --micro` for the smallest machine-facing next-step output.
- `handoff --compact` to avoid returning both `packet` and `prompt`.
- `learn query --compact` and `map query --compact` for low-context agents.
- token benchmarks for micro/compact next, handoff, learning and map queries.

Compatibility:

- Default/full outputs remain available.
- Compact modes are opt-in flags.
- Audit artifacts and evidence remain unchanged.
