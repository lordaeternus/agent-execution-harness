# Agent Execution Harness v0.14.3

Patch release focused on dispatch guidance for agents that can use subagents.

What changed:

- Added `agent-harness dispatch plan --plan plan.json`.
- Added `agent-harness dispatch next --batch --runtime subagents`.
- Dispatch returns safe serial fallback or parallel handoff packets; it does not spawn workers itself.
- Worker output validation remains in `agent-harness handoff validate`.
- Dispatch now refuses a new batch when a run already has an active task, gate or incompatible phase.
- Runnable dispatch tasks are no longer also reported as blocked.
- Task `isolation` is documented as advisory metadata in this version.

Compatibility:

- Existing serial `next --exact` flows keep working.
- Existing `handoff` and `handoff validate` flows keep working.
- There is no `dispatch validate` command; use `handoff validate` for worker JSON.
