# Agent Execution Harness v0.14.0

Token-first diagnostics for weaker agents.

- Added `doctor --coverage` to show compact control gaps by project topology.
- Added `doctor --architecture` for lightweight path/import boundary checks.
- Added optional `architecture_rules` config without new dependencies.
- Added compact coding-discipline control for surgical, verifiable execution.
- Improved repeated-failure steering with more specific small-control suggestions.
- Added token benchmark/budget coverage for the new doctor outputs.

Compatibility:

- Existing configs remain valid.
- New checks are advisory diagnostics by default.
- Full audit flows remain available; routine outputs stay compact.

Consumer update:

```bash
npx agent-execution-harness@latest init --apply
npx agent-execution-harness@latest doctor --coverage --architecture --harnessability --cwd .
```
