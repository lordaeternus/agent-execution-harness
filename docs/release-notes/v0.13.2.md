# Agent Execution Harness v0.13.2

Patch release for repeated-failure recovery.

Changes:

- Added compact repeated-failure guidance to `AGENTS.md` templates.
- Updated the short runtime protocol with the same rule.
- Agents now get clearer direction to inspect local code/history first, use docs or web only for external dependency behavior, compare two fixes, and stop after repeated equivalent failures.

Compatibility:

- No command behavior change.
- Existing install behavior remains unchanged: `AGENTS.md` is skipped, appended or overwritten according to the selected install mode.
