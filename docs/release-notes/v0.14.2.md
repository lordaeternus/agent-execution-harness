# Agent Execution Harness v0.14.2

Patch release focused on bridging approved text plans into executable harness plans.

What changed:

- Added `agent-harness plan import --from backlog.md --out plan.json --plan-id <id> --risk L2 --rollback "<text>"`.
- The importer supports the atomic Markdown task format used in implementation backlogs.
- Missing-plan errors now tell agents how to import, lint and start a plan.

Compatibility:

- Existing `plan waves`, `plan-lint` and `session start --plan` flows keep working.
- The harness still does not guess from chat history; text must be saved to a Markdown file first.
