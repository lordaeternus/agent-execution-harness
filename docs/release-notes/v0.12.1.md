# Agent Execution Harness v0.12.1

UX patch for installation and readiness checks.

Change:

- `init` now prints a short human success message by default.
- `doctor` now prints a short human readiness report by default.
- `--json` keeps the previous machine-readable output for CI, scripts and automation.

Why:

New users should not need to read raw JSON to know whether installation worked.

No protocol behavior change. Existing automation should add `--json` when it needs structured output.
