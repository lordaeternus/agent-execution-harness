# Agent Execution Harness v0.12.4

Patch release for install/update script correctness.

Fix:

- `init` now installs `agent:harness` as `agent-harness`, so users can run `pnpm agent:harness doctor`, `pnpm agent:harness --help`, `pnpm agent:harness --version` and session commands normally.
- Existing projects with the legacy `agent:harness: agent-harness run` script are upgraded safely during `init --apply`.

Compatibility:

- Custom user scripts are preserved.
- Existing harness artifacts, memory, backups and AGENTS.md content remain protected by the current safe-merge flow.
