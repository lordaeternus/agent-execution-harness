# v0.17.0

Universal runtime capabilities for agent environments.

## Added

- `runtime_capabilities` in `agent-harness.config.json` to describe the runtime instead of creating agent-specific harness versions.
- `agent-harness doctor --runtime` and `--json --runtime` for a compact serial/subagent readiness snapshot.
- Config-driven dispatch fallback so runtimes with `supports_subagents: true` can use batch guidance without passing `--runtime subagents` every time.

## Compatibility

- Existing `dispatch --runtime serial_only|subagents` behavior remains supported and takes precedence over config.
- Missing runtime capabilities default to safe serial execution.
- Worktree support remains declarative capability metadata; this release does not create automatic worktrees, forked workspaces or sandboxes.
