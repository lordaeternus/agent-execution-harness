# v0.17.2

This patch hardens the final evidence path without adding runtime complexity.

## Changes

- Final reports now require the same auto-claim coverage checked by `finish --check`, closing low-level false-completion paths.
- Task surface and required-evidence inference now share one task contract, avoiding drift between plan compilation and evidence policy.
- Strict manual gate evidence now requires external proof metadata: `--output-ref` and `--sha256`.
- Weak-agent guidance remains token-light and continues to steer agents toward `verify --exec`.

## Compatibility

No schema migration is required. Strict-mode users recording manual external evidence must include `--output-ref` and `--sha256`; use `verify --exec` for command-backed evidence.
