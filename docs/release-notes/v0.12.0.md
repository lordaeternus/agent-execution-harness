# Agent Execution Harness v0.12.0

Focused release for lightweight learning-memory maintenance.

Add:

- `learn health --compact` reports whether learning memory needs review.
- `learn audit --compact` returns a short read-only list of stale, duplicate and low-confidence candidates.
- `session start` can include `learning_health=needs_audit`, so agents can run compact audit without the user remembering commands.
- Config thresholds keep audit signals cheap and deterministic.

No embeddings, no extra reviewing agent, no automatic deletion. Audits recommend cleanup; source code, tests and current runtime evidence remain the truth.
