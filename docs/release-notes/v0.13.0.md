# Agent Execution Harness v0.13.0

Release focused on stronger weak-agent execution, safer public release gates, and tighter token discipline.

Changes:

- Stabilized the default test gate for slower machines.
- Cleaned dependency audit and added security gates to CI/release.
- Expanded dangerous-command detection for shell, PowerShell, cmd and Node eval patterns.
- Added optional structured plan controls: forbidden files, expected diff, required checks and rollback command.
- Made high-confidence codebase memory require source files and main-agent validation.
- Added weak-agent benchmark scenarios and failing thresholds for false success and missed out-of-plan diffs.
- Extended token budget coverage for benchmark output.

Compatibility:

- Existing v1 plans continue to work.
- New plan fields are optional.
- Full audit outputs remain available; compact outputs remain optimized for weak agents.
