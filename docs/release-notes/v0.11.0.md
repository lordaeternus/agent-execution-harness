# Agent Execution Harness v0.11.0

Focused release for governed learning memory.

Adds:

- `learn validate` between capture and promote, so reusable lessons must pass evidence, file, safety and failure-detail checks.
- Local `learn query` ranking with optional `--files` and `--failure-signature`.
- Short repeated-failure hints from `verify` after equivalent gate failures.
- Token budgets for validation output and repeated-failure hints.

Compatibility:

- No embeddings.
- No extra reviewing agent.
- No long learning report in routine execution.
- Existing full artifacts remain available for audit/debug.
