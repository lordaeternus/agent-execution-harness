# Agent Execution Harness v0.7.0

Strict-mode hardening release for safer low-context and non-frontier agent execution.

## Added

- Added `strict` execution mode.
- Added runtime JSON Schema validation with Ajv for versioned plan/action/config/run contracts.
- Added structured verification commands with `--exec` and `--args-json`.
- Added strict command enforcement against task `allowed_commands`.
- Added staged-file coverage to scope guard.
- Added adversarial benchmark metrics: `false_success_rate`, `repair_success_rate`, and `unexpected_diff_block_rate`.

## Changed

- `acceptance_criteria_met` now requires task evidence policy completion.
- Strict mode blocks shell-style `--cmd` by default.
- Release readiness audit now checks README/package/release-note version consistency.

## Validation

- Typecheck.
- Unit and integration tests.
- Token budget and token benchmark.
- Smoke benchmark with 7 scenarios.
- Pack dry run and release readiness audit.
