# v0.15.0

Portable patch intake for worker handoffs.

- Added `agent-harness patch intake`.
- Validate-only is the default; `--apply` runs `git apply --check` before changing files.
- Patch paths are scoped to the task `files` and rejected if they hit `forbidden_files`.
- Handoff output now supports optional `patch_file` metadata and points parent agents to patch intake after JSON validation.
- `claim auto` no longer moves a run to report while later tasks are still pending.

This does not add automatic sandboxing or worktree creation. Task `isolation` remains advisory unless the runtime implements isolation.
