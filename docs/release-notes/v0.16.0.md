# v0.16.0

This release tightens the end of an agent run and adds two lightweight inputs for weaker agents.

## Added

- `agent-harness finish --check` validates final readiness without writing the final report.
- `agent-harness plan import --kind feature-list` converts simple Markdown feature bullets into a valid harness plan.
- `agent-harness doctor --quality` prints a compact quality snapshot from existing doctor, harnessability, coverage, architecture and steering signals.

## Changed

- `agent-harness next --exact` now suggests `finish --check` before `finish` when a run is near completion.
- Feature-list import remains Markdown-only in this version. It does not add a new JSON schema.

## Not Included

- No top-level `quality` command.
- No automatic sandbox, worktree or worker spawning behavior.
- No npm publish or downstream consumer update in this code change.
