# v0.17.1

Token-economy and branch-stability patch.

## Changed

- `verify` and serial dispatch guidance prefer `next --exact --micro` for compact executor continuation.
- `handoff --compact` uses a shorter worker prompt while keeping the same validation requirements.
- Runtime docs and templates now state that agents must stay on the current branch unless the user explicitly asks for a branch change.

## Validation

- Token budget now caps `handoff_compact_chars` below the previous near-limit value.
- Token benchmark records compact next-action metrics for verify and serial dispatch loops.
- Release-readiness checks normalize CRLF/LF before matching README and changelog version text.

## Compatibility

- No schema changes.
- Existing artifacts remain readable.
- Full audit outputs and referenced logs remain available.
- The harness still does not create worktrees, sandboxes, workers or branches automatically.
