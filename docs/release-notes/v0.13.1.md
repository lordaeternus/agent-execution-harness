# Agent Execution Harness v0.13.1

Patch release for installed agent instructions.

Changes:

- Added compact operating rules to `AGENTS.md` templates.
- New installs and update installs now guide agents to read before writing, keep changes surgical, define success criteria, stop on risky ambiguity and avoid silent skips.
- Kept the rules short enough to stay within the harness token budget.

Compatibility:

- No runtime command behavior change.
- Existing `AGENTS.md` handling is unchanged: skip, append or overwrite still depends on the selected install mode.
